# Approved diagram design

The visual source is the [STE100 Wiring Sheet](https://claude.ai/artifact/RPoZeENf5WKAYYhF4eFtsr). The complete native export is `../assets/ste100-wiring-sheet.reference.html`. Keep it unchanged. The working template carries the same document reset and diagram CSS.

The sheet has a maximum width of 1240 pixels. The frame uses a 1.5-pixel border. The three-column grid has 14-pixel gaps and padding. Panels have one-pixel borders. B and C span two columns. The one-column breakpoint is 900 pixels.

Panel headers use the original square badges, 8-by-12-pixel padding, and label styles. IBM Plex Sans supplies prose. IBM Plex Mono supplies technical labels. Font files cover the original 400, 500, and 600 weights. The output embeds them. The SIL Open Font License travels with the output.

Light colors: paper #eef2f5, panel #ffffff, tint #e6edf4, ink #14202b, muted #55687a, rule #c6d1db, info #1f5fa8, good #17703f, bad #b3261e.

Dark colors: paper #0e151c, panel #151e27, tint #1c2833, ink #e4ebf1, muted #94a5b4, rule #2d3b48, info #78b4f4, good #5fca8d, bad #ff8d84.

Keep the original tree, SVG flow, status table, annotated example, limit-bar, and open-check styles. Use text or marks with status colors. Give each flow an accessible description. Use real numeric scales for bars.

Do not add gradients, hero cards, stock images, a different palette, or a different font family. New facts change the content inside the design. The original source remains the comparison target.

The unchanged reference loads Google Fonts. The working renderer embeds the local matching font files. The reference describes 2026-10-04 and remains historical evidence.
